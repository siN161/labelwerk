**Goal:** Strichcodes (Code 128, Code 39, EAN-13, EAN-8) und QR-Codes als eigenes Objekt aufs Etikett – in ganzen Druckpunkten je Modul, mit Klartext, Prüfhinweisen und Platzhaltern der Serie.

**Tech Stack:** Python ≥ 3.10, Pillow, segno, PySide6, pytest, pytest-qt, zxing-cpp (nur Tests, Python ≥ 3.12).

Spec: `docs/superpowers/specs/2026-10-19-barcodes-design.md`

**Herkunft des Codes:** Prototyp in genau dieser Task-Reihenfolge (Branch `proto-barcode`), nach jedem Task volle Suite grün mit Exit-Code 0 (1976 → 2177 → 2222); jeder Schritt von einem Reviewer geprüft und korrigiert (Kern: Klartext passt sich der Höhe an, Unterlängen nicht abgeschnitten, Code 39 nur a–z groß, Ruhezonen je Art, Grenze „Etikett zu groß“ ohne Kodieren und für Platzhalter, Einfügen lieber gedreht als kleiner, Maximieren füllt Breite und Höhe getrennt; Code-128-Optimierung gegen erschöpfende Suche geprüft; GUI: ungültiger Barcode als wählbarer Platzhalter statt lahmgelegter Arbeitsfläche, Strg+Z im Inhaltsfeld = Rückgängig des Etiketts, Anfasser/Felder/Prüfhinweis mit dem Wert der Serien-Vorschau, Inhalt auf 2000 Zeichen begrenzt, Modulfeld nimmt nur sinnvolle mm, F2/Enter, Favoriten-Vorschau).

+def _drag(obj, handle, dx=0.0, dy=0.0):
+    r = _rendered(obj)
+    old = object_rect(r)
+    x, y, w, h = old.x, old.y, old.w, old.h
+    if "l" in handle:
+        x, w = x + dx, w - dx
+    if "r" in handle:
+        w += dx
+    if "t" in handle:
+        y, h = y + dy, h - dy
+    if "b" in handle:
+        h += dy
+    return layout.resize(obj, Rect(x, y, w, h), r, handle)
