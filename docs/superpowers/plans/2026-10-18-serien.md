# Serien aus CSV/Excel und Nummerierung (Etappe 3e) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Etikett mit Platzhaltern `{Spalte}` wird für jede gewählte Zeile einer Tabelle (CSV/Excel) bzw. einer Nummerierung gefüllt und in einem Auftrag gedruckt – Schnitt nach jedem Etikett oder nur am Ende.

**Architecture:** Kern `series.py` (Tabellen als fremde Eingabe, Nummerierung, `fill` nur zum Lesen) und `Document.series`; `printer.py` druckt Listen in Teilaufträgen mit wählbarem Schnitt; die GUI zeigt auf der Arbeitsfläche die gefüllte Vorschau-Zeile (`MainWindow._view_doc`), der Reiter SERIE wählt Quelle, Zeilen und Schnitt.

**Tech Stack:** Python ≥ 3.10, Pillow, PySide6, pytest, pytest-qt.

Spec: `docs/superpowers/specs/2026-10-18-serien-design.md`

**Herkunft des Codes:** Prototyp in genau dieser Task-Reihenfolge (Branch `proto-series`), nach jedem Task volle Suite grün mit Exit-Code 0 (1818 → 1893 → 1920 → 1963); jeder Schritt von einem Reviewer geprüft und korrigiert (Kern: Zeilen nach Lücken, formatierte leere Zellen, Speicher beim Streamen, Diagrammblätter, NUL-Pfade, Zahlenformate, Trennzeichen, relative Pfade; Drucker: bytearray statt quadratischer Laufzeit, Folgeseiten, Teilaufträge mit Statusprüfung, 1 Bit bitgleich; GUI: Doppelklick, Schreibmodus mit Platzhaltern ohne Lagedrift, Reiter bleibt, „ragt über“ je Zeile, Rückfrage vor dem Rendern, Neueinlesen beim Öffnen und vor dem Drucken).

**Patches anwenden:** Jeder Task enthält zwei Patches (Tests, Implementierung) im `git diff`-Format. Den Block **byte-genau** in eine Datei außerhalb des Repos schreiben (z. +def _xlsx(tmp_path, sheets, name="t.xlsx"):
+    """Excel-Datei mit Blättern ``{Name: Zeilen}`` (erste Zeile = Spaltennamen)."""
+    book = openpyxl.Workbook()
+    book.remove(book.active)
+    for title, rows in sheets.items():
+        sheet = book.create_sheet(title)
+        for row in rows:
+            sheet.append(row)
+    path = tmp_path / name
+    book.save(path)
+    return path
